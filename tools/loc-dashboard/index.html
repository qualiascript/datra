Counting and reconstruction

Counts physical lines in tracked text, including comments and blank lines. The entire test directory and fixtures are excluded. Build/configuration files and root text files remain included. Binary files and symlinks are excluded. Only committed history is counted; uncommitted edits are not.

Original commits behind squash PRs are dated by author date. Other changes use committer dates. Imported branch history is deduplicated through Git ancestry, with merge-day reconciliation where needed. The reconstructed daily totals combine branch work and may differ from historical checkouts of master. The latest total is checked against the selected commit's full tree.

Days without changes carry forward. The seven-day rate sums the last seven calendar days’ net changes and divides by seven. The first six days have no full-window rate. The helper checks the checked-out branch every ten seconds; the page refreshes automatically.
